# Decisions

- Keep the radio procedural in code so named interactive parts and GLB export stay deterministic.
- Keep playback local-first; do not silently substitute unrelated remote audio.
- Keep record clicks non-interactive to match the physical-product interaction contract.
- Keep `dist/`, `node_modules/`, logs, and environment files out of Git.
- Use `main` as the default branch and a descriptive initialization commit.
