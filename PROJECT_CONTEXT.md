# Project Context

Retro Cyber Radio is a portfolio-style interactive radio product demo. It combines a procedural Three.js object scene with a pure HTML/CSS music panel. The current design favors a bright neutral product-showcase background, blue ABS-like housing, layered metal/glass/rubber materials, and generous framing.

The project is intentionally self-contained: no external model file is required at runtime. The model hierarchy is created in code with named parts and can be exported as a GLB from the UI.
